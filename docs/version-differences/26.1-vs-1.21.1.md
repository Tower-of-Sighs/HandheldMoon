# 26.1 与 1.21.1 的 Minecraft API 差异

核对来源：

- 26.1：`common/build/moddev/artifacts/minecraft-patched-26.1.0.19-beta-sources.jar`
- 1.21.1：`targets/neoforge-1.21.1/build/moddev/artifacts/neoforge-21.1.234-sources.jar`

以下差异均由上述源码 jar 中的实际类型/签名确认，而不是推测。

## 已确认差异

| 主题 | 26.1 | 1.21.1 | 影响的 common 文件（1.21.1 中 `exclude`） |
| --- | --- | --- | --- |
| 资源标识符 | `net.minecraft.resources.Identifier` | `net.minecraft.resources.ResourceLocation` | `client/LightSourceHighlightRenderer.java`、所有使用 `Identifier` 的 26.1 客户端代码 |
| 渲染类型 | `net.minecraft.client.renderer.rendertype.RenderType` + `rendertype.RenderSetup` | `net.minecraft.client.renderer.RenderType` | `api/raycone/impl/RayConeRendererImpl.java`、`client/LightSourceHighlightRenderer.java` |
| 渲染管线 | `net.minecraft.client.renderer.RenderPipelines` | 无对应类（1.21.1 仍用 `RenderType` 静态工厂） | `api/raycone/impl/RayConeRendererImpl.java` |
| 光照坐标工具 | `net.minecraft.util.LightCoordsUtil` | `net.minecraft.client.renderer.LightTexture` | `mixin/client/EntityRendererMixin.java`、`mixin/dynamiclight/*.java` |
| 提交式渲染 | `net.minecraft.client.renderer.SubmitNodeCollector` | 无对应类（`PoseStack` 直接提交） | `client/renderer/*.java`、`client/screen/*.java` |
| 条件物品模型 | `net.minecraft.client.renderer.item.properties.conditional.ConditionalItemModelProperties` | 无对应类（1.21.1 用 `ItemProperties`） | `client/renderer/item/MoonlightLampPoweredProperty.java` |
| 方块实体类型构造 | `BlockEntityType(BlockEntitySupplier, Set<Block>)` | `BlockEntityType(BlockEntitySupplier, Set<Block>, Registry<BlockEntityType>.Type)` | `block/FullMoonBlockEntity.java`、`block/MoonlightLampBlockEntity.java`（target 自己的注册实现） |
| 创造模式标签页 | `CreativeModeTab.builder(Row, int)` | `CreativeModeTab.builder()` | 各 target 的 `RegistryService` 实现 |
| 后处理链 | `PostChain.passes` 为可访问字段（AT/classtweaker 打开） | `PostChain` 结构不同，1.21.1 使用独立 `EffectManager` | `event/handler/EffectManager.java`、`event/handler/ShaderEventHandler.java` |
| 光照/实体渲染 Mixin | `EntityRenderer#getPackedLightCoords` + `LightCoordsUtil` | 同一入口存在，但下游 tint 注入点不同 | `mixin/client/EntityRendererMixin.java`、`mixin/dynamiclight/*.java` |

## 1.21.1 target 保留的完整实现

因为上述差异会连锁影响渲染、界面、物品和方块实体，`targets/neoforge-1.21.1` 保留了自己的一整套实现，并在 `prepareCommonSources` 中排除对应的 common 路径：

- `client/LightSourceHighlightRenderer.java`
- `client/screen/{AbstractFlashlightItemConfigScreen, AbstractLightSourceConfigScreen, FlashlightItemConfigScreen, HandheldMoonConfigScreen, LightSourceConfigScreen}.java`
- `client/renderer/{FullMoonRenderer, MoonlightLampRenderer}.java`、`client/renderer/item/MoonlightLampPoweredProperty.java`
- `api/raycone/impl/RayConeRendererImpl.java`
- `block/{FullMoonBlockEntity, MoonlightLampBlockEntity}.java`、`entity/FullMoonEntity.java`
- `item/{ColorLensItem, FullMoonItem, MoonlightLampItem, MoonlightWandItem}.java`
- `event/handler/{EffectManager, ShaderEventHandler}.java`
- `mixin/client/*`、`mixin/dynamiclight/*`
- `registry/ModKeyBindings.java`、`util/IrisCompat.java`
- `spi/AbstractClientPlatformService.java`（依赖 26.1 的界面与 `ModKeyBindings`）

未列入该表的内容（配置编解码、光源计算、网络包定义、事件逻辑、API 接口等）在 1.21.1 与 26.1 上共用 `common` 实现。
